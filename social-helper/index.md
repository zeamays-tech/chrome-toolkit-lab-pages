# Social Helper 隐私政策

生效日期：2026 年 7 月 11 日

Social Helper（中文显示名“微博超话签到助手”，以下简称“本扩展”）用于帮助用户识别其关注的微博超话，并按用户设置完成批量签到、每日定时签到、失败重试和签到结果展示。

## 本扩展处理的信息

本扩展会在提供上述功能所必需的范围内处理以下信息：

- 用户设置：定时签到开关、每日签到时间、失败重试间隔和语言设置。
- 微博超话信息：用户关注的超话名称、超话标识、超话页面地址，以及签到状态、签到名次、签到时间和微博返回的失败原因。
- 运行信息：运行日期、触发方式、尝试次数、开始和完成时间、下次重试时间及任务汇总。
- 微博页面信息：当微博接口无法返回关注超话列表时，本扩展会在微博页面内读取与超话发现和签到有关的页面内容及页面存储数据，并仅保留完成签到功能所需的超话信息和结果。
- 微博登录会话的使用：本扩展通过浏览器中已有的微博登录状态向微博发送 HTTPS 请求。浏览器会随请求使用当前微博会话；本扩展不会要求、读取或保存用户的微博密码，也不会读取或保存 Cookie 值。

本扩展不会收集用户在其他网站上的浏览记录，不会收集与微博超话签到无关的页面内容，也不会将用户数据用于广告、用户画像、信用评估或与本扩展单一用途无关的分析。

## 信息的使用方式

上述信息仅用于：

- 获取并展示用户关注的微博超话；
- 按用户操作或配置完成微博超话签到；
- 展示当天签到进度、结果、名次和失败原因；
- 安排每日签到和必要的失败重试；
- 在本地恢复扩展设置和当天运行状态。

## 信息的存储与保留

- 用户设置和签到运行状态保存在当前 Chrome 用户配置中的 `chrome.storage.local`。
- 本扩展不运营用于接收这些数据的开发者服务器，也不会把这些数据同步到开发者或分析平台。
- 用户设置会保留到用户修改设置、清除扩展数据或卸载本扩展为止。
- 本扩展仅维护一份当前或最近一次签到运行状态；新的日期或运行会覆盖旧状态。未被覆盖前，该状态会保留在本地扩展存储中。

## 信息的传输与共享

- 本扩展只会为实现关注超话识别和签到功能，向 `weibo.com`、其微博子域名及 `m.weibo.cn` 发送 HTTPS 请求。微博会依据其自身的服务条款和[微博个人信息保护政策](https://weibo.com/signup/v5/privacy)处理这些请求。
- 本扩展不会把用户数据出售给第三方，不会向广告平台、数据经纪商或其他信息转售方传输用户数据。
- 开发者及其他人员无法通过本扩展访问保存在用户浏览器中的数据。若用户主动向开发者提供问题信息，该信息仅用于处理对应的支持请求。

## 权限说明

- `storage`：在本地保存用户设置和签到状态。
- `alarms`：安排每日签到和失败重试。
- 微博站点访问权限：访问微博页面与接口，使用当前浏览器中的微博登录状态获取关注超话并执行签到。

本扩展的站点访问范围限定为 `https://weibo.com/*`、`https://*.weibo.com/*` 和 `https://m.weibo.cn/*`。本扩展不执行远程代码。

## 微信赞赏

本扩展内的微信赞赏入口仅展示随扩展打包的本地二维码图片。赞赏过程由用户在微信中自行完成，本扩展不会读取、存储或传输支付账号、交易记录或其他支付信息，赞赏与扩展功能权限无关。

## 用户的选择与数据删除

- 用户可以在扩展面板关闭定时签到，以停止后续的自动签到调度。
- 用户可以修改签到时间和重试间隔。
- 用户可以卸载本扩展，以删除 Chrome 为本扩展保存的本地数据。

## 数据安全与 Limited Use 声明

本扩展采用最小权限，仅通过 HTTPS 与微博通信，并将扩展设置和运行状态保存在 Chrome 的本地扩展存储中。

本扩展对通过 Chrome API 和微博页面处理的信息的使用，遵守 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq/)，包括 Limited Use 要求。相关信息仅用于提供或改进本扩展公开说明的单一用途。

## 政策更新

当本扩展的数据处理方式发生变化时，开发者会更新本政策、生效日期和 Chrome Web Store 中的相应披露，并在新处理方式开始前按适用要求向用户说明。

如对本政策或本扩展的数据处理方式有疑问，请通过 Chrome Web Store 商店详情页中列出的支持邮箱联系开发者。
